A little help

How do I back up my records?

Open Settings → Backup and restore → Save backup file. Choose a folder in Files and keep the JSON file somewhere you trust. Back up before deleting the app or moving to a new device.

How does restore work?

Open Backup and restore → Import backup file. Review the file summary before replacing your current records. Canceling leaves your records as they are. Recover previous records returns to the state before the last restore. If your current records matter, export a fresh backup first.

What do the percentages mean?

Routine practice is completed habit occurrences divided by planned habit occurrences in the selected period. Goal practice measures linked actions; it is separate from marking the goal itself achieved. Undo removes a completion from the count, and moving a task does not count it twice. Patterns describe scheduled days and times, not the reasons behind missed actions.

Where are language and color settings?

Use the settings button at the top right. Daylink supports Korean, English, Japanese, Simplified Chinese and Spanish. Language and color choices are saved on the device.

Does Daylink sync automatically?

This release works offline, without an account, advertising or automatic sync. You can transfer records with file backup and restore. Notifications and widgets are not available in this version.

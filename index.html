오늘

선택한 날짜의 할 일과 습관을 확인하세요. 한 번 눌러 완료하고, 잘못 체크했다면 취소할 수 있어요.

02

목록

할 일·습관·목표를 관리하세요. 이름만으로 저장할 수 있고 날짜·시간·목표 연결은 나중에 정해도 돼요.

03

성과

누적 완료와 루틴 실천율, 목표 진행 상황을 살펴보세요. 최근 7일·30일·1년의 흐름을 확인할 수 있어요.

궁금할 때, 여기서

기록을 파일로 백업하려면?

오른쪽 위 설정 → 백업과 복원 → 파일로 백업을 선택하세요. 파일 앱에서 저장할 폴더를 정한 뒤 JSON 파일을 보관하세요. 앱 삭제나 기기 변경 전에는 먼저 백업하는 것이 좋습니다.

백업을 가져오면 어떻게 되나요?

백업과 복원 → 백업 파일 가져오기에서 JSON 파일을 선택하세요. 내용 요약을 확인하고 복원하면 현재 기록이 교체됩니다. 취소하면 그대로 유지됩니다. 이전 기록 복구는 마지막 복원 직전 상태로 돌아갑니다. 현재 기록이 필요하면 먼저 새 백업을 저장하세요.

실천율과 목표 달성은 어떻게 다른가요?

루틴 실천율은 선택한 기간의 예정된 습관 수행 건 중 완료한 비율입니다. 목표 실천율은 연결된 행동의 수행 비율이며, 목표 자체를 완료로 표시하는 것과 구분합니다. 완료 취소는 집계에서 빠지고 날짜 이동은 중복 집계하지 않습니다. 미완료 경향은 예정된 요일·시간대이며 실제 실패 원인을 뜻하지 않습니다.

언어와 색상은 어디서 바꾸나요?

오른쪽 위 설정에서 바꿀 수 있습니다. 한국어·영어·일본어·중국어 간체·스페인어를 지원하며, 언어와 색상 선택은 기기에 저장됩니다.

기기 사이에 자동으로 동기화되나요?

현재 버전은 계정·광고·자동 동기화 없이 오프라인으로 작동합니다. 파일 백업과 복원으로 기록을 옮길 수 있습니다. 알림과 위젯은 아직 제공하지 않습니다.

사용 중 막힌 부분이 있나요?

기기 모델·OS 버전·문제가 생긴 순서를 알려주세요.
개인 기록이나 비밀번호는 보내지 않아도 됩니다.

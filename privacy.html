개인정보 처리방침

시행일: 2026-10-20 · Richard Lee

기기에 저장되는 기록

Daylink 1.0.0은 사용자가 입력한 할 일, 습관, 목표, 날짜·시간·반복 설정, 완료·취소·이동 기록, 언어와 색상 설정을 앱 내부 저장소에 보관합니다. 계정 없이 오프라인으로 작동하며, 앱은 이 기록을 운영자 서버로 전송하지 않습니다.

파일 백업과 복원

파일 백업을 선택하면 기록이 JSON 파일로 내보내집니다. 저장 위치는 iOS 파일 선택 화면에서 직접 정합니다. iCloud Drive나 다른 파일 제공자를 선택하면 해당 서비스의 설정과 정책이 적용됩니다. 앱은 내보낸 JSON 파일을 암호화하지 않으므로 신뢰할 수 있는 위치에 보관하세요. 복원은 현재 앱 기록을 교체하며, 마지막 복원 직전의 상태는 기기에 복구용 파일로 보관됩니다. iOS 기기 백업은 Apple 정책과 기기 설정에 따라 별도로 작동합니다.

광고와 사용 분석

현재 버전에는 광고, 광고 추적 SDK, 운영자 서버 기반 사용 분석, 제3자 로그인 기능이 없습니다. TestFlight나 Apple의 진단·피드백 기능을 이용하면 사용자가 공유한 진단 정보나 피드백이 Apple을 통해 제공될 수 있으며 해당 기능에는 Apple의 정책이 적용됩니다.

문의 이메일과 피드백

문의 시 보내주신 이메일 주소, 문의 내용과 첨부파일은 응답과 문제 확인을 위해 사용합니다. 개인적인 할 일이나 목표 내용은 보내지 않아도 됩니다. 이메일은 운영자의 네이버 메일을 통해 처리됩니다. 운영자가 보관하는 문의 자료는 문의 해결 후 1년 이내 삭제합니다.

기록의 보관과 삭제

항목을 삭제해도 기록의 일관성을 위해 과거 실행 이력은 남을 수 있습니다. iOS에서 앱을 삭제하면 앱의 로컬 데이터와 복구용 사본도 삭제됩니다. 앱 정리하기(오프로드)는 데이터를 남길 수 있습니다. 내보낸 파일과 기기·클라우드 백업은 해당 저장소에서 별도로 관리·삭제해야 합니다. Daylink 계정이나 서버 사본은 없습니다. 운영자가 받은 문의 자료의 열람·정정·삭제는 아래 이메일로 요청할 수 있습니다.

이 지원 웹사이트

이 페이지에는 광고, 분석 스크립트, 입력 폼, 자체 추적 쿠키를 넣지 않았습니다. 이 웹사이트는 GitHub Pages로 제공되며, GitHub는 자체 정책에 따라 보안을 위해 방문자의 IP 주소를 기록합니다. 앱의 할 일·습관 기록은 이 웹사이트로 전송되지 않습니다.

변경 안내와 문의
